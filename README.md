# Bubble-Gun-Cat
A 2D platformer
About the Game

Tama and the Dirty Bubbles is a charming, fast-paced 2D platformer with a strong environmental message. You play as Tama, a brave bubble-cleaning hero on a mission to purify a polluted world. Navigate through hazardous levels, collect toxic bubbles, and restore nature to its vibrant self. This game was passionately created within a strict 3-day timeframe during the Global Game Jam.

Key Features
Fluid 2D Platforming: Jump, dash, and navigate through environmentally-themed obstacles.
Purification Mechanic: Collect and neutralize toxic elements to progress through the levels.
Charming Aesthetic: Beautiful, hand-crafted 2D sprites and UI elements.
